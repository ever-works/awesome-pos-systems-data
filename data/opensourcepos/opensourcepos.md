## Overview

Open Source Point of Sale (osPOS) is a free, open-source, web-based point of sale application designed for small to medium retail businesses. It is written in PHP using the CodeIgniter framework and uses MySQL as its database back end.

## Features

- Web-based point of sale interface built with Bootstrap 3
- Sales processing and transaction recording
- Inventory management and stock tracking
- Customer records and management
- Product catalog with categories
- Reporting for sales and inventory
- PHP / CodeIgniter back end with MySQL database
- Self-hosted deployment

## Pricing

Free and open source under the MIT License.

## Deployment

Self-hosted (PHP + MySQL).
