## Overview

BTCPay Server is a free, open-source, self-hosted cryptocurrency payment processor. It is self-hosted, meaning users run their own instance and retain full control of funds and data without relying on third-party processors.

## Features

- Self-hosted Bitcoin payment processing with no transaction fees
- No middlemen, no KYC requirements
- Point-of-sale (POS) interface for retail and restaurant checkout
- Invoice generation and payment requests
- Lightning Network support for fast, low-cost Bitcoin payments
- Multiple store support with separate wallets and settings
- API and webhooks for integration with e-commerce platforms
- Native desktop and mobile apps (BTCPay Desktop, BTCPay Mobile)
- Two-factor authentication and role-based access control

## Pricing

Free and open source under the MIT License. Self-hosting costs depend on the user's own infrastructure.

## Deployment

Self-hosted.
